# Pipelines

Le pipeline DevSecOps reel vit dans
[`.github/workflows/devsecops.yml`](../.github/workflows/devsecops.yml)
— GitHub Actions n'execute que les workflows places a cet endroit precis,
impossible de les faire fonctionner depuis `pipelines/`.

Ce dossier sert de reference/documentation pour le pipeline (voir aussi
[docs/phase3-devsecops-pipeline.md](../docs/phase3-devsecops-pipeline.md)).
